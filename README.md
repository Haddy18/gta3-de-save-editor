>*Claude Speed — rendered from his in-game portrait.*
A small Windows app that finishes the last few items of your *GTA III:
Definitive Edition* save so you can unlock the **100% completion**
achievement without replaying a 30-hour game, and prepares the remaining
event-based achievements so their final triggers are available.

Tick a checkbox, save, done.

## Download

Grab **`GTA3-DE-Save-Editor.exe`** from the
[latest release](https://github.com/Haddy18/gta3-de-save-editor/releases/latest)
and double-click it — no installation, no dependencies.

## How to use

1. **Back up your save.** It lives in
   `Documents\Rockstar Games\GTA III Definitive Edition\Profiles\<PROFILE>\GTA3sf1.sav`.
2. Open the app and press **Open .sav...**
3. Tick whatever your save is still missing: story and phone missions,
   off-road races, RC car missions, rampages, unique jumps, Import/Export
   deliveries, hidden packages, firefighter / vigilante / taxi / paramedic.
4. The counters at the bottom update live: **Progress x/154** and
   **Missions x/73** are the real numbers the game uses for 100%.
5. Press **Save**. The save is written with a valid checksum, so the
   game loads it without complaining.

If the Rockstar launcher reports a cloud-sync conflict, pick **Local** —
that's normal for any edited save.

You can verify the result yourself by uploading the file to
[GTASnP](https://gtasnp.com) — everything should show green.

## Preparing the remaining event achievements

Nine achievements are awarded by the game when an event happens, not by
the save state alone: **Man Toyz**, **Furious First Responder**, **King of
Liberty City**, **Talks a Lot**, **Blood in the Streets**, **Instigator**,
**Cheaters Do Prosper!**, **Play Fetch** and **Pest Control**. Editing the
final counters does not fire those events.

With a save open, press **Prepare achievements**. The editor puts each one
at its final trigger:

- **Man Toyz** — 3/4 RC missions; complete *Diablo Destruction*. If the
  RC van is gone, use a save where RC1 was still pending.
- **Furious First Responder** — paramedic/vigilante complete and Shoreside
  fires at 19; extinguish one fire there.
- **Talks a Lot** — *Rumble* pending; complete it when D-Ice calls. If he
  does not call, use a save where Rumble was still pending.
- **Cheaters Do Prosper!** — 1,999 exploded cars; blow up one car.
- **Play Fetch** — Portland Docks complete and Shoreside missing only the
  Cheetah; deliver it.
- **Pest Control** — crane missing only the Rhino; deliver it.
- **Instigator / Blood in the Streets** — 9 rampages passed and 11 live.
  Complete one for Instigator, nine more to reach 19, and the last one for
  Blood in the Streets. This needs a save that still has live rampages;
  if yours no longer has any, the editor skips this part and tells you to
  use an earlier backup (for example `GTA3sf1 - copia.sav`).
- **King of Liberty City** — unlocks with the other eight.

The button changes the progress counter (a 100% save will go down), so use
**Save as...** and keep your original 100% save. Achievements you have already
unlocked stay unlocked.

## Notes

- Works with any slot (`GTA3sf1.sav`, `GTA3sf2.sav`, …) and finds
  everything by structure, so it isn't tied to one specific playthrough.
- Single-player only. It edits your local save file; it does not touch
  online services. Still — always keep a backup.
- Missing a feature or found a bug? Open an issue.

## For developers

The whole editor is a single standard-library Python file:

```
python gta3_save_editor.py            # GUI
python gta3_save_editor.py --selftest # 70 checks against real saves
```

Releases are built automatically by GitHub Actions when a release is
published (PyInstaller, Windows).
