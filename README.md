>*Claude Speed — rendered from his in-game portrait.*
A small Windows app that finishes the last few items of your *GTA III:
Definitive Edition* save so you can unlock the **100% completion**
achievement without replaying a 30-hour game.

Tick a checkbox, save, done.

## Download

Grab **`GTA3-DE-Save-Editor.exe`** from the
[latest release](https://github.com/Haddy18/gta3-de-save-editor/releases/latest)
and double-click it — no installation, no dependencies.

## How to use

1. **Back up your save.** It lives in
   `Documents\Rockstar Games\GTA III Definitive Edition\Profiles\<PROFILE>\GTA3sf1.sav`.
2. Open the app and press **Open .sav...**
3. Tick whatever your save is still missing: story and phone missions,
   off-road races, RC car missions, rampages, unique jumps, Import/Export
   deliveries, hidden packages, firefighter / vigilante / taxi / paramedic.
4. The counters at the bottom update live: **Progress x/154** and
   **Missions x/73** are the real numbers the game uses for 100%.
5. Press **Save**. The save is written with a valid checksum, so the
   game loads it without complaining.

If the Rockstar launcher reports a cloud-sync conflict, pick **Local** —
that's normal for any edited save.

You can verify the result yourself by uploading the file to
[GTASnP](https://gtasnp.com) — everything should show green.

## Notes

- Works with any slot (`GTA3sf1.sav`, `GTA3sf2.sav`, …) and finds
  everything by structure, so it isn't tied to one specific playthrough.
- Single-player only. It edits your local save file; it does not touch
  online services. Still — always keep a backup.
- Missing a feature or found a bug? Open an issue.

## For developers

The whole editor is a single standard-library Python file:

```
python gta3_save_editor.py            # GUI
python gta3_save_editor.py --selftest # 51 checks against real saves
```

Releases are built automatically by GitHub Actions when a release is
published (PyInstaller, Windows).
